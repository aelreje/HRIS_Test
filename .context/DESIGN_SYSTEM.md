# Design System: iREPLY High-Fidelity

## 🎨 Color Palette
| Token         | HEX       | Usage                                  |
| :------------ | :-------- | :------------------------------------- |
| **Primary**   | `#1E4D8C` | Brand Identity, Header, Main CTA, Logo |
| **Secondary** | `#1E293B` | Headings (Slate-800)                   |
| **Accent**    | `#0EA5E9` | Focus, Active Nav Indicators (Sky-500) |
| **Success**   | `#10B981` | Approved/Present Status (Emerald-500)  |
| **Warning**   | `#F59E0B` | Pending/Late Status (Amber-500)        |
| **Danger**    | `#E11D48` | Denied/Absent Status (Rose-600)        |
| **Canvas**    | `#FAFBFC` | Main Background                        |

## 📐 Measurements
- **Grid:** 8px base (Standard spacing: 16px, 24px, 32px).
- **Radius:** 
  - `16px`: Main Cards.
  - `12px`: Inputs, Buttons, Stat Cards.
  - `full`: Status Pills, Avatars.
- **Sidebar:** `320px` width.
- **Inputs:** `56px` fixed height.

## 🔤 Typography
- **Font Family:** Inter (Sans-serif).
- **Logo:** `font-black`, `tracking-[-0.05em]`, uppercase.
- **Nav Items:** `text-[15px]`, `font-bold` (Active) / `font-medium` (Inactive).
- **Headers:** `font-black`, `tracking-tight`.
